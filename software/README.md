# Support for the UNIT DevLab PDM MP34DT05TR Microphone Breakout

This repository provides resources and example code for using the UNIT DevLab PDM MP34DT05TR Microphone Breakout, a high-performance digital microphone based on the MP34DT05 MEMS sensor. The breakout board is designed for easy integration with microcontrollers and development boards, making it ideal for audio applications such as voice recognition, sound level monitoring, and more.
